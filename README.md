# Web Technology Lab – CSVTU

This repository contains 25 Web Technology Lab experiments performed as part of the college practical curriculum.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Experiments Covered
- Basic HTML tags, forms, tables and multimedia
- Semantic HTML5
- CSS styling, selectors and responsive design
- CSS layouts and advanced features
- JavaScript variables, operators, loops and functions
- JavaScript events and DOM manipulation
- Form validation and calculator
- Image gallery and slideshow
- PHP programming and file handling
- PHP GET and POST methods
- MySQL database operations
- PHP and MySQL connectivity
- Login system using sessions and cookies
- Mini Student Management System

## Purpose
The purpose of this repository is to practise web development concepts and maintain practical programs for learning and academic reference.

**University:** Chhattisgarh Swami Vivekanand Technical University (CSVTU)

**Note:** This repository is intended for educational and learning purposes.
